# 开源前删除与脱敏清单

| 原始路径或类别 | 处理 | 当前候选 |
|---|---|---|
| `secrets/**` | 删除所有密码/桥接 token，不只是加入忽略规则 | 已排除 |
| `state/**` | 删除机器标识、登录 home、联系人指纹、群聊、任务和暂停状态 | 已排除 |
| `runtime/**` | 删除二维码、桌面截图、登录画面及模型临时工作目录 | 已排除 |
| `config.json`、`config.json.*` | 删除个人配置与备份，重建假数据示例 | 仅保留 `config.example.json` |
| `bin/net-guard` | 不发布本机二进制；从 C 源码自行构建 | 仅保留 `net_guard.c` |
| `benchmarks/**` | 原始群聊重放、截图、状态和脚本整体私有保存，不直接复制 | 已排除；此候选测试报告单独记录 |
| `__pycache__`、日志、数据库、备份 | 不提交 | 已排除并加入忽略规则 |
| `guardrails.py`、persona/style、worker、compose、tests | 真人、账号、群名、地名、路径替换成虚构演示值 | 已处理；仍需人工审查角色画像组合 |
| `tests/test_os_sandbox.py` | 去除专属应用的凭据路径，保留合成越界测试 | 已处理 |
| README、安装说明 | 删除私人环境描述，说明缺少许可与服务接入边界 | 已重写 |
| `corpora/**` 和来源说明 | 不把私有整理直接打包；保留公开链接及权利核查记录 | 原始文件已排除 |

`config.json`、`secrets/` 等未来生成文件仍需保持 Git 未跟踪；`.gitignore` 不会清除已经提交的历史。如果以后发生公开泄露，应撤销/轮换凭据，再清理历史，不能只删当前文件。
