# 主许可证决定

2026-10-29，按项目所有者授权，选择 MIT，根目录 LICENSE 为完整许可证文本，SPDX 标识为 MIT。版权署名使用 `wechat-bot contributors`，避免披露本机用户名或现实姓名；该集合署名不等于创建法律实体或代替贡献归属确认。

选择理由：项目当前主要是 Python 自动化及配套 C 辅助源码，优先便于复用和二次开发；MIT 文本和再分发条件简洁。明确保留已有 MIT 来源的版权和许可通知。

Apache-2.0 同样是宽松许可证，但包含更明确的贡献者专利授权、专利诉讼终止，以及修改声明和适用 NOTICE 保留要求。如果未来有重要专利贡献或组织级知识产权安排，可以重新评估未来版本的许可；已经授出的许可不能靠删文件撤回，第三方代码也不能任意重新许可。

本次没有把任何未知授权来源、网页语料、WeChat/agy 二进制或账号服务重新许可为 MIT。当前其他来源核查事项仍见 LICENSE_REVIEW.md。
